# SkillsMonitor

SkillsMonitor displays floating messages for all skill gains including skill ups, loot, and money.

## Supported clients

Tested on WoW Forever. Reportedly runs on Classic. Although not tested extensively, the AddOn runs on higher previous expansions, particularly TBC Anniversary and retail. However, not that SkillsMonitor only recognizes Classic-era herb and ore nodes.

## Installation

Install the `SkillsMonitor` folder in your World of Warcraft `Interface/AddOns` directory, then enable SkillsMonitor from the AddOns list.
