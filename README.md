# SkillsMonitor

SkillsMonitor displays floating messages for all skill gains including skill ups, loot, and money.

## Supported clients

Tested on WoW Forever. Reportedly runs on Classic. Also runs on higher level expansions, but it only recognizes Classic-era herb and ore nodes.

## Installation

Install the `SkillsMonitor` folder in your World of Warcraft `Interface/AddOns` directory, then enable SkillsMonitor from the AddOns list.
